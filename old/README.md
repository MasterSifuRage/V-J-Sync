# Lưu trữ (archive)

Thư mục này chứa **tài liệu và mockup giao diện cũ**, không dùng để chạy ứng dụng production.

| Nội dung | Mô tả |
|----------|--------|
| `*.html` | Mockup tĩnh (HTML + CSS inline) trước khi chuyển sang React |
| `vj-logo.png` | Bản sao logo (cùng thư mục mockup) — bản chuẩn dùng cho app nằm ở `../frontend/public/vj-logo.png` |
| `đặc tả web.md`, `đặc tả màn hình.md`, `các màn hình.md` | Đặc tả sản phẩm / nút bấm / luồng màn hình |

Ứng dụng chạy thực tế nằm trong `frontend/` và `backend/`.
